# tep-ihm-web

Web HMI for the simulated Tennessee Eastman plant, in React and TypeScript. It rewrites the screens of [`tep-ihm`](https://github.com/Green-Cinnamon-Labs/tep-ihm) v1: the live process diagram, following ISA-101, the supervisor panel and the analytics page.

It talks only to [`tep-ihm-api`](https://github.com/Green-Cinnamon-Labs/tep-ihm-api).

Part of the [Hefesto](https://github.com/Green-Cinnamon-Labs/spec-hefesto) research line. Work is tracked in this repository's issues and on the [GCLabs board](https://github.com/orgs/Green-Cinnamon-Labs/projects/12).
